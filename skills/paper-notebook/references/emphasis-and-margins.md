# 知识重点与页边讲解

正文建立完整解释，强调标记呈现知识层次，右栏补足就近理解所需的信息。三者围绕同一个知识点编写。

## 先确定值得记住的内容

起草每节时，先明确本节的核心概念、决定结果的关系、推理中的关键步骤。完成正文后，再从实际文字中选取对应短语。重点应帮助读者解释、推导、比较或应用本节知识。

- **概念及其关系**：选择专业术语、定义中的本质属性、公式各项之间的关系。只圈“数据”“结果”“变化”等泛词，通常不能提示这一节的内容。
- **决定性条件**：选择真正影响结论的条件，如复利的计息周期、统计指标的分母、预测时可获得的特征。条件的作用应在正文中得到解释。
- **推理与证据**：选择使结论成立的理由、关键变换、文本细读的字词、案例中的经营机制。例题中的最后一个数字通常只是核算结果，不能占据整节的强调中心。

按读者基础取舍。已有微积分基础的读者学习梯度下降，应突出导数、更新方向与步长的关系；逐次相减等基本算术无需另设回忆问题。文学重点取自作品的语言与解释，商学重点取自经营关系与指标含义。

## 用字体和颜色表现知识层次

关键术语及定义的决定性短语使用 `bold`；本节最重要的概念或关系可同时使用蓝色 `red` 标记（`color: "#285f9e"`）。影响推理或计算的条件使用朱红色 `#b1483d`；绿色 `#357344` 可用于经推导得到的结果。全册保持同一语义配色。黑板内使用与底色对比清晰的浅色强调，正文保持可选文字。

先保证主概念醒目，再选择少量圈线指出推导理由。颜色不按段落轮换，也不按出现频次自动分配。不要将连词、题目编号、一般动作或整段文字当作重点。相同短语可叠加加粗、颜色与一种圈画；同一类标记无需重复添加。同节后续出现的相同术语按需要标记，首次定义和推理转折优先。

`study.marks[].text` 必须精确匹配 `textOf(block)` 的实际文字。使用完整且能辨认含义的短语，避免单个泛用字；文学炼字、数学符号等可按学科需要标注。参数说明、表格内容和代码同样可以被原生标记。标题中的词不能用作正文锚点。

## 右栏以补充讲解为主

`cues` 是页边知识注释，默认采用陈述句。可选 `title` 命名具体概念，`text` 写一两句完整说明。按当前段落的需要选择一种内容，无需为每页凑齐栏目：

| 正文内容 | 右栏可补充 |
| --- | --- |
| 首次出现的术语 | 定义中的必要含义、词义或符号释义 |
| 抽象关系 | 同一情境的短例子，给出具体对象、条件和结果 |
| 推导转折 | 等号成立的理由、数量关系或几何意义 |
| 图表与数据 | 坐标、比较对象、指标分母及图中关系的解释 |
| 文学原句 | 词语古义、句法、对仗、意象与情感推进 |
| 实际模型 | 条件变化对结果的具体影响 |

补充说明须增加信息。正文已有完整定义时，可补一个应用或解释它与相邻概念的联系；无需把定义换词再写一次。主体、对象、数值和术语与所指段落一致。比较或例子需要较长推导时，放入正文的 `example` 或 `callout`。

每条注释指定本页真实 `blockId`；文字注释同时提供 `anchor`，取所解释的原句短语。图像注释可直接引用图像块。注释随原句续页并对齐所在行，点击可定位原文。每个关键段落按需要保留一条有信息量的注释，其余空间用于个人批注。不要在正文内的 `study.explanations` 与右栏重复放置同一段解释。

## 提问的使用条件

用户需要主动回忆或练习时，可以使用问题。一个有用的问题包含明确对象、已给条件和需要推断的关系，正文或邻近图表提供充分依据；复习者应能据此形成具体答案。

删除无上下文的“为什么？”“说明什么？”“看见了什么？”以及只要求复述紧邻单词、报出图中最低点或完成已掌握算术的问题。不要为了问句形式，将完整解释截成一个突然出现的问号。非练习型右栏优先直接说明其知识内容。

## 不同学科的实例

| 段落 | 应强调 | 可采用的右栏讲解 |
| --- | --- | --- |
| 均方误差 | 均方误差、平方后取平均、较大误差的贡献 | **平方惩罚**：误差从 1 增至 3，损失贡献增为 9 倍，拟合会更重视这些偏差较大的样本。 |
| 梯度下降 | 负梯度方向、学习率、步长收缩条件 | **更新幅度**：导数给出局部变化率；参数移动量为 −ηJ′(w)。同一位置增大学习率，会放大本次移动。 |
| 复利通式 | 期末值作为下期基数、增长因子、参与期数 | **指数的来源**：每经过一期，余额乘一次 1+r；同一因子连乘 n 次，得到 (1+r)ⁿ。 |
| 《春望》首联 | 破、在、深；山河恒常与人事凋零 | **“深”的作用**：草木蔓生写出城中荒芜，与“城春”的时令相接，春景中包含战乱后的凋残。 |
| 盈亏平衡 | 单位贡献、固定成本、覆盖关系 | **单位贡献**：80 元售价扣除 50 元单位变动成本，每件留下 30 元覆盖固定成本。达到平衡后，每多售一件，利润增加 30 元。 |
| 集合去重 | 元素相等、顾客编号、统计粒度 | **订单与顾客**：同一顾客新增订单时，记录数增加，编号集合的大小保持不变。两项指标分别反映交易次数和顾客人数。 |

## 交付前的内容判断

脱离颜色读一遍所有强调短语：它们应能呈现本节的知识结构。逐条对照右栏与对应原文：注释解释了什么，增加了哪项信息，能否放在这一句旁边直接理解？删除不能回答这三个问题的内容。

构建报告的 `teaching` 提示缺失锚点、重复注释、过长强调等可直接检查的问题。数量和匹配通过后，仍须完成上述语义判断。检查实际 HTML 的加粗、颜色、圈画、明暗主题和续页对应关系。
