# 教材编写与内容验收

产物是可以独立学习的教材式电子笔记。先确定学习目标、先修关系、覆盖范围和可用时长，按[学科与学习阶段](subject-pedagogy.md)建立内容路径。文学展开文本细读，数学展开关系与推导，案例研究展开经营或社会机制。短篇也应闭合一个问题；长期课程需要章节依赖、术语一致性和可追踪的进度。时间少时缩小范围，不用删去关键理由来假装讲完一门课。

## 概念、例题与练习各司其职

- `concept`：给出准确的定义、符号、单位、适用条件和必要的边界。概念首次出现时解释，后文沿用同一术语；不要用一个口号代替定义。
- `prose`：承接因果、解释“为什么”，连接前后知识。普通解释保持连续文字，不将每句话装成一张卡片。
- `formula` 与 `steps`：逐步列出变换和理由，交代使用的定理或假设。重要公式单独占块，推导可分为若干完整阶段；不把半个等式推到下一页。公式下方使用 `parameters: [{symbol,name,description}]` 逐项解释符号，每项单独一行，写清含义、单位、条件、参数变化或具体数值；整体假设放 `text`。函数至少搭配一种有解释作用的坐标图、计算路径或数值对照，帮助读者对应输入、运算与输出。
- `example`：明确“教学例题”，完整写出已知、求解目标、每一步的依据、计算和结论；自拟数值标明教学用途。后续案例可沿用同一对象，逐步增加复杂度，避免一章换三个无关故事。
- `comparison`、`chart`、`diagram`：承担对比、数据或结构的解释，图后说明读法和结论。图文中的变量、计数、方向与数值必须一致。
- `exercise`：只有用户选择需要练习时使用；题目、提示与解析区分，不把带答案的例题伪装成练习。主观题使用参考要点，不自动判分。

篇幅随范围调整。通常 30–45 分钟的系统导读应有若干章节和约 8–16 张内容纸页，每页聚焦一个可讲清的问题；深入课程可以分册。这个范围是容量参考，不是凑页数指标。不要用十几个小标题、每节两句话冒充完整教材。交付前检查每个目标是否有解释、论证、完整例子或直接证据支撑。

## 有解释力的图文，而非装饰

对空间、数值、流程、分类、比较等视觉上更清楚的内容，主动提供实际图解。系统教程通常每一至两页有一幅承载知识的图、数据图或带标注示意；对照表另行统计；不要求每页插图，也不重复同一种三框箭头图。机器学习可组合：样本散点与预测直线、误差残差、训练与验证流程、复杂度与泛化、算法对照表。

默认使用手绘风格解释图，优先可编辑的原生 SVG、`diagram`、`chart`；表格承担维度对照。按[配图规范](multimodal.md)选择图形类型、尺寸比例与生成方式。允许检索可靠互联网资料获取依据和可复用素材，或自行绘制手绘风格的解释图。配图需用圈画、短文字、勾记或箭头辅助解释关键部位，使用 `figure.annotations`；不要遮住原有标注。技术几何与数值必须准确，手绘只影响线条与图框。照片、复杂生物形态等使用带来源和许可的图片；图片内嵌，并提供说明与 alt。不要写“此处插入图片”却不交付图片，不把外链图片算作离线资产。没有检索能力时说明限制并使用可核实知识与原创图解，不编造来源。

## 纸页组织

默认 `cornell`：正文区用于讲解，右侧栏 `cues` 写与原文相连的定义、短例子、推导理由、图表读法或条件说明，底栏 `summary` 按需写综合关系或迁移结论，只在本部分末张纸页显示一次；正文已说明的内容不重复总结，可省略 `summary`，保留批注空间。每页预置内容须有区别，其余位置留给用户批注。不要在每页复制同一句“你学会了吗”。单幅大图、长推导或宽表可以改为 `reading`，充分使用横向宽度；复杂内容宁可另起一页，也不要缩成小字或塞进窄栏。避免过长页标题。

按[知识重点与页边讲解](emphasis-and-margins.md)编写右栏。`cues` 默认使用完整陈述句，可选 `title` 命名具体知识点，`text` 提供正文之外有用的解释。文字注释指定 `blockId` 和精确 `anchor`，图像注释引用图像块。问题用于用户需要的复习或推理练习，须给足对象与条件，并有邻近材料作答依据。删去脱离上下文、显而易见、只要求照读数字或机械计算的问题。每个关键段落保留真正有帮助的注释，避免同义重复，留出个人批注空间。

页标题与小标题直接点明对象或关系，如“斜率与截距”“均方误差与损失函数”。减少连续使用“怎样……”“如何……”“看图理解……”以及“从……到……”的标题模板；只有确实围绕一个疑问展开论证时才使用问句。定义、主解释、补充条件和操作提醒须分层：同一块内换话题用空行分段；独立的异常值影响、适用限制、单位核对可用短 `callout`，配具体标题、手绘铅笔边线和淡纸色底纹。不要将必要条件混在长定义里，也不要给每一段加框。容器、表格、示意与批注统一为类手绘笔记风格，技术几何、数值与文字始终准确清楚。纸页安排紧凑，避免大面积闲置；优先减少标题区、块间距和容器内边距，保留 2.05 的舒展行距。

通过 `study.role` 标识定义、直觉、推导、例题、证据、要点或回忆；`study.frame` 可选 plain/pencil/tape/double/margin，或 auto 由阅读器按稳定 ID 分配。相同类型与章节保持节奏，变化服务于辨识。少量圈注、旁注和黑板强调真正需要记忆的原句，避免整段高亮。

**正文加粗、文字变色、圈点勾画是三项独立的默认交付要求。** 每个讲解部分必须明确选择核心概念加粗与短语变色，不能只画彩色下划线而保留整篇黑色正文。先选择核心概念、决定性关系与条件，再确定数量：`{"text":"模型参数","kind":"bold"}` 将术语本身加粗；`{"text":"独立检验","kind":"red","color":"#b1483d"}` 将文字本身改为红色；概念可用蓝色 `#285f9e`，条件或边界可用红色 `#b1483d`。同一概念允许加粗并变色，保持语义一致，避免整段加粗或多色散布。黑板内选择与底色对比清晰的浅色。封面、目录、来源、纯图页按内容需要处理。用户明确要求纯文本或无标记时才省略。

圈点勾画属于默认作者排版，需要在源数据中明确写出 `study.marks`，阅读器不会自动挑选重点。按内容选择：核心术语用 `circle`，关键条件用 `underline`，决定性词句用 `dots`，已推导出的结论用 `check`；荧光、波浪、框选、括注和星标按需使用。根据知识密度选择少量短语，封面、目录、来源页和纯图页无需硬凑；不要要求每页九种齐全。用户明确要求无圈画时才省略作者标记。

例如 `{"id":"growth-key","type":"prose","text":"复利以每一期的期末值作为下一期的基础。","study":{"marks":[{"text":"期末值","kind":"circle"},{"text":"下一期的基础","kind":"underline"}]}}`。`text` 必须是实际组件正文的完整、非空子串；不要用标题中的词去标记正文，使用 `bold`、`red` 实现原生文字样式，不要用 Markdown 星号、emoji 或图片中的笔画冒充原生标记。作者标记属于正文 `study.marks`，不可仅存在于个人 `userState.annotations` 中。交付前检查构建报告中的作者标记数量、类型和未标记页，并在实际离线成品上确认可见。

## 标题与层次

标题直接写知识对象，例如“《春望》的首联与反衬”“Costco 的会员制与商品销售”“平方误差的权重”。不填写装饰性 `subtitle`，不在标题下插入编号、学习路线或写作意图。必要的区分合并到节标题或正文。每部分首页展示节标题，续页使用阅读器的层级与续页逻辑。

## 表达与事实

直接解释具体对象、动作、条件和结果。保留准确术语、否定、不确定性和来源位置。例题逐步列出数值、理由和单位。引用不足时写明待核实；不虚构个人经历，不预设读者理解有误，不凭空添加“常见误区”。避免对话开场、空泛鼓励、装饰标签、机械排比和反复总结。

优先应用 anti-defensive-writing：每句应增加知识、证据或推理。删除防备假想质疑的解释、显而易见的区分、无依据的纠错和空泛拔高。条件在实际参与推理的位置说明一次。中文采用自然语序，主体、动作和对象清楚。删除假口语、空泛比喻、反驳句式和语义重复；正文直接陈述观点，比较使用平行表达。按[中文去 AI 味与统一审阅规范](writing-review.md)完成一轮语义审阅；该规范整合 anti-defensive-writing、Humanizer 与 Humanizer-zh，来源和 MIT 声明随工具包保留。

按[知识重点与页边讲解](emphasis-and-margins.md)逐条检查标记的知识价值和右栏的信息增量，再检查：目标覆盖 → 先修链 → 定义/例题/练习区分 → 数值与推导 → 图文一致 → 正文加粗与变色、作者圈点的原句锚点及实际显示 → 来源与事实口径 → 横竖屏排版。没有实际检查的项目明确列出，不声称已通过。

默认行距 2.05，并保留段落、图注与图文之间的空隙。按定义、条件、推导结果分配圈、线、勾、点与短旁注，每个普通教学部分至少有两种合适的圈点样式；结合实际图像、图表或示意图交错解释，不能仅把连续 Markdown 正文换成纸色。
