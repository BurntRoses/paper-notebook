# 2.2 升级记录

生成入口仍按对话平台与编程智能体分开，每类仅需一句话。获取阅读器、询问缺失的学习基础与目标、生成配图、校验及文件交付规则都留在仓库内部。

## 教材写作与配图

整合 anti-defensive-writing、Humanizer 和 Humanizer-zh 的共同原则：直接提出观点，以具体依据、条件与推导推进内容，清理空泛铺垫、重复免责、拔高和客服腔。真实限定、技术否定、证据强度、引文和个人记录保留。固定提交、改编说明和许可见[写作规范](../skills/paper-notebook/references/writing-review.md)。

生成前规划有解释作用的配图。默认纸张配色、手绘轮廓、清晰标签；关系和数据优先 SVG，场景与有机形态可使用平台提供的图像生成能力。系统教程按内容安排实际图解，表格单独统计。图片应内嵌，不交付占位符或外链依赖。

`figure` 统一 image / diagram / chart 的四档尺寸、六种比例、左右中对齐和 sketch/precise 模式。图框稳定占位，图片延迟解码不改变分页；超高对象保留完整滚动视口。纸页容得下的配图等比缩小，标签和图注保留。手机数据图加大刻度字号并采用两列图例。复利示例加入面积 SVG 与单利/复利数据图，机器学习示例应用新协议。

Node 与 Python 构建报告均有 `contentReview`：措辞线索、实际配图与表格数量、各页配图、未引用素材和超过 300 KB 的资产。它只提供审阅建议；模型仍需核对事实、段落和图文关系。

## 运行与构建

- 圈画撤销仅保存标记及作者标记隐藏状态，保留其间新增的便签和作答。正文与内嵌图片不进入 60 步历史。
- 每个表格按完整源表计算列对齐，再复用于表头、正文和续页；阅读和 PDF 使用同一源块索引。
- 原生选择框使用一个全局外部点击监听器；DOM 观察器只增强新插入的选择框，不随圈画 SVG 更新扫描整个页面。
- 图表范围逐点计算，避免数组展开；框图行坐标用累计值计算；续页计数只处理当前源页。
- 示例时间戳、空白模板 ID、ZIP 时间与条目顺序固定。版本号统一从 package.json 读取；组件和 schema 的 Skill 副本由发布脚本同步。

[本机基准](verification/reader-performance.json)对照修改前的两条实际路径。标记样本含 3 MB 内嵌图片数据字符串和 200 个标记，表格样本为 60 行、4 列、前置 200 块；记录五次运行中位数。数字仅对应此设备与样本，不代表所有笔记的总体提速。快照字节数是序列化载荷，不等于浏览器内存测量。

## 验证与体积

53 项模型与往返测试通过。Chromium、WebKit 实测四档尺寸、全部比例、九种形状、精确轮廓、移动刻度、延迟图片解码、选择框、反复分页、A4 表格续页对齐和离线资源；工作台回归覆盖圈画、便签、书签、键盘、续学导出与离线重开。Node/Python 对话包生成的内容审阅一致，官方阅读器验证与替代外壳拒绝检查均通过。

两次连续完整构建的 28 个产物逐字节一致，见[可重复构建报告](verification/reproducible-build.json)。

详见[配图与稳定性报告](verification/quality-browser-report.json)、[工作台报告](verification/workspace-report.json)、[对话包报告](verification/conversation-package-report.json)。

复利示例约 1.94 MB，机器学习示例约 2.01 MB；新增配图为轻量 SVG，没有增加图片生成 SDK、外部运行时或完整字库。现有纸张纹理约 48 KB，压缩收益有限，保留效果。用户素材的大图与未用副本会在构建报告提示，是否压缩需结合细节价值判断。图像模型是否可用由宿主平台决定；绘图与排版规则不会虚构工具能力。

## 2.2.1 下载兼容

备用手动下载改用 `paper-notebook-upload.zip`，内含原始 `paper-notebook-conversation.zip` 和简短上传说明。浏览器只解压外层时，用户直接上传内层 ZIP；外层保留为 ZIP 时也可直接上传。获取脚本识别两种格式，仍校验内层完整性、路径和必要文件，不递归解压任意 ZIP。AI 自动下载继续使用原始构建包。外层按存储模式封装，不重复压缩，体积仅增加不到 1 KB。实际浏览器的自动解压由浏览器和系统设置控制，递归解压时仍支持重新压缩整个 runtime 文件夹。

## 2.3 首页与视频

复制指令并入首页 `#create`，两条外部提示仍各一句话。旧制作链接跳转到首页相应区域。移除“生成后在这里阅读”和空白阅读器推广入口；下载的成品 HTML 直接打开。右上角“快速开始”菜单集中制作、试读、演示与 GitHub，支持键盘、Esc 和外部点击收起。

横竖影片维持 1080p、30 fps 和完整内容，合计从 52.6 MB 降到 30.9 MB。首页立即请求两版视频，原生播放器各自保留缓冲，旋转不重新设置 src。Chromium / WebKit 验证提前缓冲、延迟响应、32 秒跳转、暂停/播放和快速反向旋转；浏览器自行决定预加载深度。


## 2.4 阅读交互与播放

首页文案精简，演示和机器学习试读采用直接的标题。底部仅保留翻页导航；选中文字弹出快捷栏，右键纸页打开选区工具或纸页菜单，点击空白处关闭。快捷栏提供加粗、多种文字颜色和恢复原色。已选颜色可撤销、重做并随 HTML 保存。

右侧栏直接显示并编辑便签，同时列出书签和续学清单。关联便签保留原文锚点，独立便签用于自由记录。桌面默认显示右栏，窄屏按需打开；沉浸阅读保留页眉与两侧栏入口。页右上角移除续页标签。

翻页下一帧启动，动画期间暂停相邻页生成并延后草稿保存。视频改为单播放器优先加载当前方向，每版约 5.6 MB；首页和封面展示图压至每张约 75–81 KB，屏幕外的试读器按需加载。
