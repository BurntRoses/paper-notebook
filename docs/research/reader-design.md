# 阅读器与宣传设计参考

2026-10-21 检索并读取以下原始资料，参考关系见下。未复制网站图像、音乐、字体或页面代码。原创代码绘制纸张、海报与动效；音乐由 Web Audio 合成。

- Cornell Learning Strategies Center：[The Cornell Note Taking System](https://lsc.cornell.edu/how-to-study/taking-notes/cornell-note-taking-system/)。提要、记录、回顾的区域关系，应用为 Page.cues / blocks / summary；无固定教学成效承诺。
- [Apple Books](https://www.apple.com/apple-books/)。参考纸页作为主要视觉、安静背景与以真实阅读内容展示产品的方式；未复刻品牌及资源。
- [Material Design 3 · Motion](https://m3.material.io/styles/motion/overview)。参考连续性、速度层级、短交互与较长叙事转场的区别。阅读过渡 260–420ms；宣传时间轴随节拍切换。
- [WAI-ARIA · Modal Dialog Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。采用原生 dialog、标题关联、关闭与焦点恢复；键盘替代路径独立于指针手势。
- [PostgreSQL Aggregate Functions](https://www.postgresql.org/docs/current/functions-aggregate.html)。核对示例 COUNT(*) 与 DISTINCT 的统计语义。
- Humanizer 固定版本记录见 Skill 的 writing.md 与 licenses/。采用直接陈述、减少无信息对比/结语、禁止补造细节的编辑原则。

宣传短片叙事：需求 → 选择 → 结构 → 阅读 → 标记 → 练习 → 文件交付。72 BPM，4/4，每 8 拍进入新场景，共 7 个场景，约 46.7 秒。音轨为原创合成，不含外部采样。HTML 动画默认静音，支持播放、暂停、进度和音量开关；减少动态时停留在静态首帧。文件视频记录同一 Canvas 与音轨。
