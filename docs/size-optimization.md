# 单文件体积优化

实测对象为本次修改前后同一批构建产物。MB 采用十进制；完整字节数见 [size-report.json](verification/size-report.json)。

| 产物 | 原大小 | 现大小 | 减少 |
| --- | ---: | ---: | ---: |
| 空白阅读器 | 14.76 MB | 4.03 MB | 72.7% |
| 机器学习教程 HTML | 4.15 MB | 1.98 MB | 52.3% |
| 产品笔记 HTML | 4.38 MB | 2.01 MB | 54.0% |
| 对话构建 ZIP | 11.20 MB | 2.89 MB | 74.2% |

原空白阅读器中，字体 CSS 与内嵌字体占约 94%。完整字库约含 4.69 万字符，原分片每片最多 768 字，使用少数字符也会带入大量未用字形。

现在默认内嵌常用字符 8424 个，包含 GB2312、原界面核心、希腊/西里尔字母和常用科学符号。原界面核心保留，其他分片最多 64 字，成书时按内容筛选。未覆盖的生僻字继续保留为文字，用系统字体显示；不再为任意未来编辑携带完整 Unicode 字库。完整原始字体仍在仓库，仅用于重建。

保留字形的轮廓坐标和字宽已逐字校验。机器学习教程的首屏截图与修改前逐像素一致，正文与全书分页一致。公式字体、纸张纹理、图示、标记、作答、保存记录和源数据均保留。未给未提供的用户 HTML 文件作故障诊断，也未测量远程模型实际下载速度。

占用较大且收益低的完整生僻字库已移出默认运行包。运行时纹理仅约 48 KB，压缩它们对总大小收益很小，故保留原效果。概念类小示例此前已只用核心字库，大小仍约 1.71 MB。用户自己加入的大照片、扫描页或截图可能成为新的主要占用，生成时只下载实际用到的素材，并按显示尺寸选择分辨率；公式和标签保持清晰，成品不在打开时联网取素材。

对话包由 AI 优先复用或自动下载，实际下载失败或下载受限时才请用户上传。获取工具后，Node 与 Python 构建均无需网络或依赖安装。生成的两类 HTML 都已单独复制到空目录，在 Chromium 断网模式和 WebKit 阻断外部依赖的条件下打开、显示正文与圈注并再次导出；没有其他资源请求。记录见 [standalone-size-report.json](verification/standalone-size-report.json)。
