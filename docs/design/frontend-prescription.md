# 界面组件与验收

本轮按用户指定的本地「前端处方」3.21.2 实施。保留共享离线阅读器、象牙纸、文楷、图文批注、页边便条、练习与原有翻页效果。用户已有的纸色、字体和阅读偏好优先于默认值。

## 逐项核对

- 对齐：同级字段与操作共用起点，设置按短字段并排；桌面、半屏、手机检查实际边界。
- 字阶：必要状态和设置字号可读，字体选项展示自身字体。
- 边界：纸张选择不叠加描边和阴影；焦点由当前组件提供。
- 颜色与主题：共用令牌；深浅主题同步正文、浮层、禁用和选中状态。
- 状态：默认、悬停、按下、键盘焦点、选中、禁用、加载、成功、复制受限与网络失败。
- 输入：组合输入不触发阅读快捷键；菜单和按钮的方向键不翻动纸页。
- 连续性：快速切换、重复复制、调整窗口、关闭/重开设置保留实际状态。
- 性能：单阅读器复用，样例按需加载；使用现有资源，不引入整套新框架。
- 文案：按钮写动作，状态说明实际结果；保留必要错误和恢复入口。

此记录描述本地化采用关系；各规范不写入全局提示词或其他项目。

## 本轮验证

Chromium、WebKit 均通过上述交互状态，覆盖 320–1440px、短窗、复制受限、首次载入失败、示例请求失败、快速切换、键盘操作与减少动态。主要文字令牌的浅色最低对比度约 5.71:1，深色最低约 6.33:1。85 项模型与工具测试、便携包测试通过；六例离线打开、作答与批注导出通过。10 份当前产物完成三种视口的 293 张物理页检查及 source-bound finalize，无布局问题。具体结果见 `docs/verification/prescription-ui-2026-11-12.json`。

原有的 `src/reader/typography.css` 数学字体修改单独保留，未混入本轮提交。
